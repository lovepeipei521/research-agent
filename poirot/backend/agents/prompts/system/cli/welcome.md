Hello, I'm an agent that can chat about ideas, look up information, and conduct deep research with you.

You can:
- Chat directly      Discuss ideas, ask questions, check weather, etc. Tools available.
- /report           Organize what we just discussed into a report
- /expert           Switch to deep research mode (mandatory plan + reflection + auto-report)
- /default          Switch back to default mode (lightweight chat)
- /help             View all commands

When you're ready for a formal report, just say "generate report" or type /report.
